# Security policy

fpga-sim-core is a software simulation library and demo. It is not
production software and is not connected to any network or hardware, but
memory-safety and correctness bugs in the C++ code are still worth reporting.

## Reporting a vulnerability

Please report privately rather than in a public issue.

- Preferred: use GitHub's private vulnerability reporting (the "Report a
  vulnerability" button on the repository's Security tab), if it is available.
- Otherwise: email heykavofficial@gmail.com with a description, the affected
  file or function, and steps to reproduce.

This is a personal project maintained on a best-effort basis. There is no
guaranteed response time or fix schedule. I will try to acknowledge reports
and, where a report is valid, fix it and credit the reporter if they want that.

## Supported versions

Only the latest commit on `main` is supported.
